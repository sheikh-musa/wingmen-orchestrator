### Findings from this review round, fixed in `e48cf93`
1. **(LOW) Tautological test assertion** — `tests/console/resources.test.js`'s original line `assert.ok(failedCard.indexOf("could not measure") === -1 || true)` always passes regardless of its left operand, silently failing to verify its own stated intent. Fixed: line removed; the adjacent `assert.strictEqual(failedCard.indexOf("%"), -1, ...)` already covers the real invariant (a failed sample never renders a frozen metric number).
2. **(LOW) Missing `.pill.stale` CSS rule** — `resources.html` defined `.pill`, `.pill.err`, `.pill.na` but not `.pill.stale`, even though `resources.js` emits `class="pill stale"` for an old-but-ok sample. It rendered amber only by coincidence (the unstyled base `.pill` defaults to amber-ish via `--amber-soft`/`--amber` vars already in that rule) — fixed by adding an explicit `.pill.stale` rule so the color is a deliberate choice, not a coincidence that breaks silently if the base `.pill` default ever changes.
3. **(LOW) `wsl.runner_service` missing-value styling inconsistency** — `cubeashtRows()` rendered a missing `runner_service` as plain bold `.rv` text ("could not measure") instead of the greyed/italic `.na` style every other missing field on the page uses, making a missing reading look like real data at a glance. Fixed: now wraps the fallback in `<span class="na">`, matching `measureRow()`'s convention. New test (`cubNoRunnerHtml`/`runnerRowHtml`, isolates the Runner-service row specifically rather than matching any `.na` string in the card, which the first draft of this test got wrong too — caught and fixed in the same round).
