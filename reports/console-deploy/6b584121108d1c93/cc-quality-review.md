## Architecture (as verified)
The hosted process (wingmen-core) holds **no tmux and shells to no lane script**. Two action shapes:
- **PROXY** (reset / lane-boot / lane-down / apply-armed / apply-dry-run): validated in the hosted layer, then forwarded to the console on the lane's **own host** (env-configured `CONSOLE_UPSTREAM_URL`/`_HOSTS`), whose Mini `app.py` re-applies its own guards and shells to the vetted scripts. No upstream for the host → 503, **never** a local shell.
- **LOCAL** (assign / ask-close): the same vetted DB-only scripts the Mini runs (`console_assign.py`/`asks_close.py`); missing script or no writable DSN → 503.
- **Hard-refused pre-auth (403):** backlog, switch-token, switch-group, switch-all, set-pointer, set-group-pointer, add-token, apply-queue-cancel — the dangerous credential/bulk surface is not even probeable from the public URL.

## The six required checks — all verified

**(1) Every hosted action is bearer + roster + singleton-refused + typed-confirm; unknowns fail closed.**
`_authed()` requires `Bearer ` + token present + `len ≥ 24` + `hmac.compare_digest`. Dispatch order: kill-switch(503) → bounded body read (≤64KiB) → pre-auth 403 list → 404 if not an action route → **auth(401)** → JSON-object parse(400) → handler. Each handler re-validates (charset, `_PROTECTED` + `cc-*` refused 403, live `fleet_lanes` roster else 400, `confirm==target` else 400). Proven by `test_hosted_server.py`, which asserts `upstream.calls == []` **and** `run.assert_not_called()` on every guard-failure — i.e. a failed guard yields **no proxy and no shell**.

**(2) The proxy can't be coerced to an arbitrary upstream or a local shell on an unmapped host.**
`session` → host comes from `agent_status.host` (DB, not user input); host → base URL from the operator's env map; unmapped host (e.g. gzbai) → 503 fail-closed. Proxy `path` is a fixed literal per handler (no path injection); `base` is env-configured tailnet only. `test_lane_on_unmapped_host_503_fail_closed` + `test_no_upstream_configured_503_never_local` (`run.assert_not_called`) confirm it.

**(3) /api/token-truth strips ALL fingerprints — proven on the REAL payload.**
The hosted endpoint proxies GET then `_strip_fps(payload)`. I ran the **production `_strip_fps` over the actual `_tt.json`** the gate render captured (the local Mini token-truth, which legitimately carries fp): all **four** distinct 12-hex fps — the 3 known **plus an unknown `d8518d915d56`** — stripped; **zero** 12-hex runs remained; **zero** residual `fp`/`*_fp` keys; and account/model/session labels survived. In the payload every raw fp lives under `fp` / `expected_fp` (rows) or `fp` (registry) — all matched by `_strip_fps` (`k=="fp" or k.endswith("_fp")`); `account`/`expected`/`expected_default`/`token_pointer_name` are labels, summary is counts. Strip is **complete**.

**(4) The Apply relaxation is scoped to the reversible token/model switch and does NOT weaken the money/irreversible bar.**
`_handle_apply_armed` sets `arm=None`. In `_resolve_armed_apply`, `arm` is used **only** for the account-scope check (`account not in arm["accounts"]`) — so dropping it removes **only** the account-allowlist. Everything else is retained and independent of `arm`: `kind ∈ {token, model}` (else 400 — **no money/irreversible kind is reachable**), `CONSOLE_R4_ENABLED` (503 without — default off), `confirm==session`, gazzabyte fail-closed (`_FORBIDDEN_TOKEN_BASENAMES`/`_FPS`), pointer-must-resolve, remote-body refused, per-lane cooldown. The queued fire re-validates the **R4 flag** at fire time (`test_queued_apply_revalidates_r4_flag_at_fire_time` → `arm-expired`). `test_apply_armed_resolver_rules_still_fail_closed` proves gazzabyte still 400s **without** the arm. The genuinely dangerous ops (switch-all / add-token / set-pointer) are **hard-403 pre-auth** on the public console and **unchanged** on the Mini. `require_verified_authorization`/`_r4_current_arm` are untouched and retained (see note A).

**(5) Boot / Stand-down fail closed on the winddown gates.**
`_handle_lane_action` runs, before any subprocess: JSON shape → charset → singleton/`cc-*` protection (403) → `fleet_lanes` roster (503 if lookup fails, 400 if unknown) → `confirm==session` → inflight/cooldown. Then exactly `bash lanes.sh up <lane>` or `down <lane> --kill` — **never `--force`** (`test_lane_boot_valid_runs_lanes_sh_up_exactly`: `--force`/`--kill` both absent; `test_lane_down_...`: `argv == [.., "down", <lane>, "--kill"]`, no `--force`). The winddown gates (busy / unread bus / stale handoff / staged composer) live inside `lane_winddown.py` and stay in force.

**(6) Mute/Pin honestly stubbed; Recycle carries confirm; no faked fires.**
fleet.js: Mute/Pin → `toast("… no backend yet — not wired")`, fire nothing. Worker-lane Recycle → not-wired toast (only the 3 resettable singletons POST `/api/reset`, and the server enforces `confirm==body` regardless). Boot/Stand-down/Apply go through an in-sheet typed-confirm strip (**not `window.prompt`** — iOS suppresses it in a standalone PWA); the fire button arms only when the typed name equals the target, and `fireConfirmed` re-checks before firing. The client is not trusted — **both** the hosted and Mini layers re-enforce every guard.
