# TDU/ADCDA target operational workflow (operator-supplied 2026-07-07)

Source: workflow diagram from the tdu team (logs/tg_media/photos_file_54.jpg). Operator asked: analyze + integrate, expect gaps. This is the TARGET end-to-end; each node must be mapped to a built surface or flagged as a gap.

## Phase 1 — PREPARATORY (onboarding)
1. **New Joiner** enters the system.
2. **Fill up form** — registration + credentials declaration.
3. Branches:
   - **HR: Format + Certificates Upload** (HR formats the record, uploads certificates).
   - **OPS Team verifies credentials and assigns vocation access** (credential check → role/vocation grant).
4. **New joiner gains access to: Training Calendar + Onboarding Material (TOU)**.
- Side input — **Resourcing per session**: 2 Trainers, 2 TCs, up to 18 Specialists (live viewing enabled).

## Phase 2 — DUTY (training day)
1. **Book training date** — via calendar, Mon–Thu only.
2. **Arrive at classroom**.
3. **IN: Scan attendance** — photo + geo-tag.
4. **Regulator verifies attendance** — late arrivals require regulator approval.
5. **OUT: Scan attendance**.
6. **Regulator verifies & closes attendance**.

## Phase 3 — POST (reporting & payroll)
1. **Compile attendance & training report**.
2. Branches:
   - **Submit report to HR** → **HR updates employee/training records**.
   - **Submit report to Finance** → **Finance processes salary/payment**.

## Analysis needed (built-vs-target gap map)

- Onboarding form + credentials declaration; HR certificate upload; OPS credential-verify + vocation/role assignment.
- Training calendar (Mon–Thu booking constraint); onboarding material (TOU) gating on access grant.
- Session resourcing model (2 Trainers / 2 TCs / ≤18 Specialists; live-viewing).
- Attendance scan IN/OUT with **photo + geo-tag**; **Regulator** role: verify + late-arrival approval + close.
- Report compilation; dual submission to HR (records) + Finance (payroll/salary).
- Role model coverage: Trainer, TC, Specialist, Regulator, HR, OPS, Finance.
