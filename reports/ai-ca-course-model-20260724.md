## 3. The "daily fires" (what forces re-plans; the ripple is the real problem)
1. **Lesson-status disputes = the #1 admin drain** — instructors report conflicting completion → schedule amended several times/day → indent resubmitted → Premier strain. Ripple: one disputed ✔ → changes coverage cursor → changes gate-eligibility → moves an exam booking → moves the indent.
2. **Whole-group assessment failure** (FF theory attempt-1 wipeout, §4) → insert revision/review/attempt-2 for multiple groups into a tight window.
3. Absence/dismissal (OOC), equipment/PPE shortfall (blocks ground training → front-load theory), facility loss (diesel-spill zone ban), safety directives, weather/heat, client-requested changes, BAPT re-rounds competing for scarce Mon-Thu days.

**Core ripple principle the AI must encode:** change one group's coverage OR one shared resource (a BAPT day / a truck / the ≤200 SCBA budget / a venue) → recompute gate-eligibility → re-book downstream assessments → regenerate the weekly indent → re-notify. Tightest coupling = the scarce Mon-Thu BAPT lane + the 2-consecutive-day PT blocks.
