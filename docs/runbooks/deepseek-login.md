# DeepSeek console: one-time login (Musa, over Screen Sharing)

1. **Run** (on the Mini, over Screen Sharing so a real window can open — not over SSH/tmux): `cd ~/wingmen/orchestrator && .venv/bin/python3 scripts/deepseek_console.py login --headed` — use the venv's python, not the system `python3` (which doesn't have `playwright` installed and will fail with `ModuleNotFoundError`). No `playwright install chromium` step is needed for this: login launches real Google Chrome via Playwright's `channel="chrome"` (verified directly, incl. in a brand-new venv with no browser install step run at all) — it only needs Google Chrome.app itself present (already installed on the Mini), not Playwright's bundled Chromium.
2. **What you'll see**: a real Google Chrome window (not Playwright's bundled Chromium — DeepSeek's human check flags the bundled Chromium's automation fingerprint) opens on the DeepSeek API Keys page. Sign in by hand (your normal DeepSeek login), wait until the API Keys page is actually showing, then switch back to the terminal and press Enter.
3. **Confirm it persisted**: the script itself prints `Login saved to the persistent profile. Future runs can be headless.` and exits 0 — if it instead says the session still looks logged out, just rerun step 1. (I separately re-verify headlessly with `deepseek_console.py list-clients` before relying on it for anything live.)
